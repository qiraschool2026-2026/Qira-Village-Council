# الموقع الرسمي لمجلس قروي قيرة

موقع إلكتروني ثابت (Static Website) لمجلس قروي قيرة — محافظة سلفيت، جاهز للاستضافة مباشرة على GitHub Pages أو أي استضافة أخرى دون الحاجة لخادم أو قاعدة بيانات.

## محتويات المشروع

```
qira-council-site/
├── index.html        الموقع بالكامل: HTML + CSS + JS + الصور (مضمّنة Base64) في ملف واحد فقط
├── images/           نسخة أصلية من الصور (للتعديل المستقبلي فقط، غير مستخدمة مباشرة من الموقع)
│   ├── village.jpg
│   └── logo.png
└── README.md
```

**ملف `index.html` مكتفٍ ذاتيًا بالكامل** — الصورتان (الشعار وصورة القرية) مضمّنتان داخله مباشرة بصيغة Base64 بدل الربط بمسار خارجي. هذا يعني:

- الموقع يعمل ويعرض الصور حتى لو نقلت `index.html` لوحده لأي مكان، أو رفعته لأي استضافة، دون الحاجة لرفع مجلد `images/` معه.
- لا مشاكل روابط صور مكسورة بسبب مسار خاطئ أو نسيان رفع مجلد الصور.
- مجلد `images/` أُبقي فقط كنسخة مصدرية احتياطية إن احتجت تستبدل صورة لاحقًا (بالتنسيق الجديد يلزمك حينها إعادة تحويلها إلى Base64 ودمجها في الكود — أو اطلب ذلك مباشرة).

## ⚠️ ملاحظة عن الشعار

تم استخدام الشعار الرسمي الحقيقي لمجلس قروي قيرة (الصادر عن وزارة الحكم المحلي) وهو مُضمّن الآن داخل `index.html` مباشرة.

الموقع مجهّز أيضًا بآلية احتياطية (Fallback): في حال حدوث أي خلل بعرض الشعار، سيظهر بديل بحرف "ق" بدلًا من رابط مكسور.

## ✅ جاهزية الموقع للرفع على GitHub

تم فحص الموقع والتأكد مما يلي، بحيث يعمل مباشرة دون أي مشاكل:

- جميع الروابط للملفات (CSS / JS / الصور) نسبية (Relative Paths) — تعمل سواء استضفت الموقع على نطاق مستقل أو داخل مستودع فرعي مثل `username.github.io/qira-council/`.
- كل الملفات المُشار إليها في الكود موجودة فعليًا بنفس الاسم وبحروف صغيرة (خوادم GitHub حساسة لحالة الأحرف Case-Sensitive، بخلاف بعض الأجهزة الشخصية).
- تمت إضافة ملف `.nojekyll` لمنع GitHub من معالجة الموقع كملف Jekyll، لضمان تحميل كل الملفات كما هي دون أي معالجة إضافية.
- تمت إضافة `.gitattributes` لضبط ترميز الملفات النصية والحفاظ على سلامة ملفات الصور عند الرفع.
- تم التأكد من تطابق جميع وسوم HTML (فتح/إغلاق) دون أخطاء بنيوية.
- الموقع لا يحتاج أي إعدادات خادم أو قاعدة بيانات أو خطوة بناء (Build Step) — ملفات ثابتة بالكامل.

## الاستضافة على GitHub Pages

1. أنشئ مستودعًا (Repository) جديدًا على GitHub، مثلاً باسم `qira-council`.
2. ارفع جميع ملفات هذا المجلد إلى المستودع (بالحفاظ على نفس البنية).
3. من إعدادات المستودع Settings → Pages:
   - اختر Source: **Deploy from a branch**
   - اختر الفرع `main` والمجلد `/root`
   - احفظ.
4. بعد دقيقة أو دقيقتين سيظهر رابط الموقع بالشكل:
   `https://<اسم-المستخدم>.github.io/qira-council/`

يمكن لاحقًا ربط الموقع بنطاق خاص (Custom Domain) من نفس صفحة الإعدادات إن توفر نطاق باسم المجلس.

## تعديل المحتوى

الموقع بالكامل صفحة واحدة (`index.html`) مقسّمة لأقسام واضحة بالتعليقات العربية:

- **عن المجلس** — نص تعريفي وبيانات أساسية (رئيس المجلس، البريد الإلكتروني...).
- **رئيس المجلس** — بطاقة باسم الرئيس، يمكن استبدال الأيقونة بصورة حقيقية لاحقًا.
- **عن القرية** — نبذة جغرافية عن قيرة.
- **الخدمات** — أربع بطاقات (الفواتير عبر واتساب، البريد الإلكتروني، فيسبوك، الشكاوى).
- **الإعلانات** — تظهر حاليًا كقسم فارغ بتصميم أنيق. لإضافة إعلان:
  افتح `index.html`، ابحث عن قسم `id="news"`، واستبدل صندوق "لا توجد إعلانات" بكتلة مثل:
  ```html
  <article class="news-item">
    <time datetime="2026-09-20">20 أيلول 2026</time>
    <h3>عنوان الإعلان</h3>
    <p>نص الإعلان بالتفصيل...</p>
  </article>
  ```
  يمكن تكرار هذه الكتلة لأي عدد من الإعلانات.
- **تواصل معنا** — بيانات التواصل وخريطة تفاعلية لموقع القرية.
